Smart Start

Dashboard design directions

Four visual directions for the member dashboard, each showing the same information: the goal and what has been set aside, where the file has reached, what happens next and what to do now. Only the dashboard is drawn. Open each one and compare them in your own time.

  • Option A

    Editorial Calm

    Quiet, generous and unhurried. Reads like a well set page rather than a control panel.

    • The figure that matters is set large and alone, with the supporting figures smaller beside it.
    • All nine stages sit on one rail, with an open ring on the stage in progress.
    • Warm off white ground, hairline rules and no shadows, so nothing competes with the words.
    View dashboard→ (Option A, Editorial Calm)

  • Option B

    Current direction

    The direction already built. A dark banner over a light working area.

    • The goal and its photograph lead, carried in a dark band across the top.
    • White cards on a light grey ground, with the stage the file has reached on a row of its own.
    • This is the live implementation, shown here unchanged for comparison.
    View dashboard→ (Option B, Current direction)

  • Option C

    Working Dashboard

    Busy in the useful sense. Every figure and next step is visible without scrolling far.

    • White modules on a cool ground, closer to the financial products members already use.
    • The nine stages are grouped into three phases, with a marker on the phase in progress.
    • The next action sits in its own tinted module so it cannot be missed.
    View dashboard→ (Option C, Working Dashboard)

  • Option D

    Instrument Panel

    Dense and precise. The whole dashboard settles inside one screen, with nothing important below the fold.

    • A narrow sidebar and a slim bar hand the rest of the screen to the work itself.
    • The next action is the only saturated surface, so the eye has one anchor instead of four cards competing.
    • The same two column pair repeats down the page, so a later module joins a rhythm that already exists.
    View dashboard→ (Option D, Instrument Panel)

Each direction is a design study of the dashboard only. The rest of the product is unchanged and continues to run on the current direction.
