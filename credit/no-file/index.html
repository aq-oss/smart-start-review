I do not think I have a file

We check whether a file exists under your details. Often one does, under an old address.

Cannot be undone. This opens your file on the alternate plan, where challenges do not apply.

What is the same

Your goal, your baseline and your learning set work exactly as they do for everyone else.

What is different

There is nothing to read back and nothing to dispute until a file exists, so those stages wait.

What it never does

Looking places no new inquiry, and it cannot start a file that is not there.

What the check is

A look for a file is a pull like any other.

Four things about a look for a file, and none of them changes your credit.

It looks for a file under your detailsThe same details a pull uses, so it goes through the same authorisation step.
An old address is the usual reasonA file follows your history rather than where you live now.
It places no new inquiryNothing about looking changes what a lender sees.
It creates nothingIf there is no file, looking for one does not start one.

If there is no file

A file that does not exist yet is not a failure and it is not a refusal. It means there is nothing on record to read back to you, so there is nothing to challenge, and the work becomes building a record rather than correcting one.
